relative  Boolean
True if the link should use a relative path. False if it should use an absolute path.
config  WorksetConfiguration
A WorksetConfiguration object specifying the worksets to open when creating the link. Leave as if the file is not workshared. Optionally, this may also be for a workshared file, in which case Revit will open all worksets.
