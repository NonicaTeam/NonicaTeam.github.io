Contextual2The geometry object is visible in some contexts, but not in others. This type of geometry is always returned by GeometryOptions, even when Revit is in a context where the geometry should not be visible, but only if IncludeNonVisibleObjects is true. Examples of geometry of this class include Solids representing insulation and lining for MEP ducts and pipes.
Highlight1The geometry object is visible, but is affected by highlight or prehighlight special coloration. This type of geometry is returned by GeometryOptions if IncludeNonVisibleObjects is true.
Invisible3The geometry object is never visible. This type of geometry is never returned by GeometryOptions but may be obtained by other API operations.
Visible0The geometry object is always visible. This type of geometry is always returned by GeometryOptions
